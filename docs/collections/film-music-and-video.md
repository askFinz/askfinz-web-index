## Key points

### What you can do with it

Find the exact release — Title matching cannot tell a remaster from a remake.

### Filed to answer

Which release is this exactly — the original, the remaster or the reissue?

### Written to

A new record is a newly published title. A revision replaces the text on the record that already exists rather than adding a second one, so the count does not double.

### Where it stops

It is not a streaming catalogue. Where you can watch or listen to something is a different question from what the release is.
