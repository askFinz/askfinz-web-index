## Key points

### What you can do with it

### Filed to answer

What does the specification actually require here, in the normative text?

### Written to

A new record is a newly published specification. A revision replaces the text on the record that already exists rather than adding a second one, so the count does not double.

### Where it stops

It is not a conformance test. It will tell you what a specification requires; whether an implementation meets it is a separate exercise.
