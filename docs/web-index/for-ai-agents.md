Chat Answers backed by live, indexed knowledge rather than what a model happened to memorise.

Ask the same question in Chat and in Search and both are drawing on the same library — not two products with two different views of the web that happen to disagree.

Chat for a conversation, Research for a cited project, Search for a direct lookup, News for what's fresh — pick the shape that fits what you're doing, and all four are reading from the same place.

## Frequently asked

### So how do I actually use it?

Through the apps built on it. Ask a question in Chat, start a project in Research, search directly, or read a News briefing — all four are reading from the same live index behind the scenes.

### Does every app see the same data?

Yes — there is one index, not four separate ones. A page indexed for one surface is available to all of them the moment it's read.

### Why not just sell index access — wouldn't that be simpler?

It would be a different business. Today the index exists to make askFinz's own apps better, and keeping it that way is what lets it grow toward whatever those apps need next rather than toward what an external contract requires.
